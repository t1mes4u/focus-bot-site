Политика конфиденциальности

Focus bot – личное приложение одного пользователя. Оно не предназначено для других людей и не собирает их данные.

Какие данные Google использует приложение

Через Google Calendar API приложение читает события основного календаря владельца и создаёт, изменяет и удаляет события в этом же календаре. Запрашивается единственное разрешение – «просмотр и изменение мероприятий в календарях» (calendar.events).

Как данные хранятся и кому передаются

Данные календаря обрабатываются на устройствах владельца (его компьютер и домашний сервер) и нигде больше не хранятся. Они не передаются третьим лицам, не продаются и не используются для рекламы. Токен доступа хранится локально в файле, доступном только владельцу.

Ограниченное использование

Использование приложением данных, полученных из Google API, соответствует Google API Services User Data Policy, включая требования ограниченного использования (Limited Use).

Отзыв доступа

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.

Контакт

Вопросы – владельцу приложения по адресу, указанному на экране согласия Google.

Privacy policy (summary). Focus bot is a single-user personal application. It uses the Google Calendar API (scope calendar.events) only to read and manage events in its owner's own calendar. Data is processed on the owner's devices, is never shared with third parties and is not used for advertising. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
